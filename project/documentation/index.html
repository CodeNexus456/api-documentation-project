Client Application API

Complete reference documentation for integrating client applications, handling authentication, and interacting with endpoints.

Export OpenAPI YAML

Overview

The Client Application API is organized around standard REST principles. All requests require valid JSON payloads with appropriate HTTP headers, and will return predictable JSON responses accompanied by standard HTTP status codes.

Environment Base URL Status
Production https://api.example.com Live
Staging https://staging-api.example.com Active

Authentication

To access protected resources, clients must include the Bearer token returned by the authentication endpoint in the Authorization request header:

HTTP Header 
Authorization: Bearer <your_jwt_token>

Tokens remain valid for 24 hours from creation.

HTTP Status Codes & Error Handling

Every response includes an HTTP status code indicating the outcome of the request:

Status Code Type Description
200 OK Success Request succeeded as expected.
400 Bad Request Client Error Required parameters are missing, or payload formatting is invalid.
401 Unauthorized Client Error Authentication failed or authorization token is invalid/expired.
403 Forbidden Client Error The client does not have permissions to access the requested resource.
404 Not Found Client Error The requested resource does not exist.
500 Server Error Server Error An unexpected error occurred while processing the request.

Authentication Endpoints

POST /api/login
Public Endpoint

Description: Authenticate an existing user with email and password credentials to receive a session token.

Request Headers

Header Type Required Description
Content-Type string Yes Must be application/json
Accept string Optional Recommended application/json

Request Body Parameters

Parameter Type Required Description Example
email string Yes Registered user email user@example.com
password string Yes Account password password

Request Payload

application/json 
{
  "email": "user@example.com",
  "password": "password"
}

Example cURL

cURL 
curl -X POST https://api.example.com/api/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "password"
  }'
