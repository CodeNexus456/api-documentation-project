# API Documentation Tool

A simple and developer-friendly API documentation project built using OpenAPI/Swagger. It organizes API endpoints, parameters, request/response examples, and error responses in an easy-to-understand format.

## 🚀 Features

- Clear API endpoint documentation
- OpenAPI/Swagger specification
- Request and response examples
- Parameters and headers documentation
- HTTP status codes
- Error response documentation
- Easy API navigation
- Clean and responsive documentation UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenAPI
- Swagger UI
- Git & GitHub
